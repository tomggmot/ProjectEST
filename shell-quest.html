// words before pipes. commands before scripts. //

Shell fluency works like spoken language. You don't learn to write sentences before you know any words. This game teaches you the words first — commands, then flags, then pipelines.

Ten lesson groups. Practice rounds, timed tests, combat waves, and boss fights based on real Eastslide tasks you've already done or will do. The final boss: stand up a container from scratch, one command at a time.

Progress saves automatically. You can blame localStorage if it disappears.

// Decoder Ring — the rosetta stone of flags
THE FLAG DECODER RING
Single-letter flags follow consistent patterns across most Unix tools. The short flag is almost always the first letter of the long form. Memorize the word, remember the flag forever. When confused: command --help
-l is a useful liar — same letter, different words, same logic:
ls -l → long format  |  grep -l → list filenames  |  wc -l → lines count  |  ssh -l → login user
